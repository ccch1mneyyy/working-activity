## Compat decisions needed before the 0.1.7 migration

1. **`tool/result` correlation (rows 12-16) — functional break, highest impact.** The tracker keys active tools on `event.data.message.content[0].toolCallId`, which is `undefined` in 0.1.7-rc.2, so `activeTools.get(undefined)` always misses and the handler returns early. Consequences on this host: `toolCount` never increments (the done line and the TUI's tool badge report 0), `activeTools` is never drained (it grows for the whole turn, `primaryTool()` keeps showing the earliest tool, and the phase never returns to `thinking` after tools), the done card can never use the failure prefix (`doneQueue` stays empty), and the `data.error` probe at `:354` is unreachable. Fix: read `event.data.message.toolCallId` (equivalently `event.data.message.source.callId`) and `event.data.message.isError`, and keep `event.data.error` only as a secondary detail. Then delete the now-false comment at `status.ts:349-350`. *Status at the end of this audit: already implemented in the uncommitted WIP described in the revision note (`src/compat/tool-result.ts` + `src/status.ts`), but not yet in the published artifact this machine runs — so the break is still live at runtime.*
2. **Streaming deltas (rows 6-7) — signal loss.** `case 'assistant/chunk'` is dead, so the whole live-delta path is inert: no `thinking` phase promotion from the stream, no `⏵` narration extraction, no token/s estimate, no `lastChunkAt` freshness. The replacement is `ctx.on('agent/assistant-stream', ({ agent, frame }) => …)` with `frame.type === 'chunk'` and `frame.chunk` being the same `StreamChunk`. Decide explicitly whether to (a) subscribe to the new event, or (b) derive narration from `assistant/message.stream` at settlement (compact records, not deltas) — and do **not** do both, it would double-count.
3. **`session.events` (row 22) — latent crash in the invariant companion.** `for (const event of session.events)` throws `TypeError` on any non-empty store. Replace with `session.snapshotEvents()` (both it and `ownEvents()` are declared `@deprecated` but are the only readers available), or drop the boot-time sweep and keep only the `internal/dispatch` half.
4. **Decide the status of the `tuiPrompt` seam (row 27) and the client half (rows 33-34).** The prompt-slot path cannot fire on this host; the live status line reaches the TUI through dsh-tui's own `ActivityTracker` sidecar, which calls the same tracker methods. Worth documenting as the real contract rather than leaving a slot registration that never resolves. The client half needs a decision on `@deepseek-ai/dsh-client-runtime` and on who supplies `snapshot.activity`.
5. **Wire (or delete) the unused signals deliberately (rows 35-38, 39).** `onModelSwitch` / `onCompact` / `onInterrupted` / `onGitBranch` have no caller in `src/`, while a downstream consumer (dsh-tui's sidecar) calls them from its own plumbing. If the plugin should own them: `request/header` `reason: 'change'` for a model switch (compare `header.config.model`, since `'change'` also fires for tool-set/sampling changes) and `user/message` with `source.kind === 'compact-checkpoint'` for compaction. Drop the `{ kind: 'plugin', plugin: 'compact' }` fallback — it cannot occur.
6. **Fix the test fixtures (row 41)** so the suite fails on the current host instead of passing against the rc.6 shapes; otherwise none of the above can regress-test. Both halves matter: the unit fixtures hard-code `assistant/chunk` and `tool-result` blocks, and the integration harness runs the plugin's own rc.6 `dsh-agent-loop`. Bumping the plugin's dev line off `0.1.0-rc.6` also makes `status.ts:349-350`'s comment and `invariant.ts:53`'s `session.events` compile errors instead of silent runtime breaks.
7. **Keep `registration.ts` (row 21), but re-check its premise when the composition changes.** It works on this machine because every persistence package is a junction to one physical tree. The root-vs-`./types` split (`KNOWN_SESSION_EVENT_TYPES` is two distinct `Set` instances in one package) means "every reachable copy" is only true for the readers actually consulted.
